# Smekal File Compare

**Free Windows file comparison tool for comparing files and identifying differences.**

Smekal File Compare is a Windows utility developed by **Smekal Solutions** to compare files and identify differences between their contents.

## Features

- Compare files and identify differences
- Identify changes between file versions
- Simple Windows interface
- Free for personal and commercial use
